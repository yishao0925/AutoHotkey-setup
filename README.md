# AutoHotkey 腳本功能說明
本專案包含兩個針對 Windows 環境設計的 AutoHotkey v2 實用腳本，分別負責瀏覽器分頁的精準控制與日規鍵盤的符號正確對應：

## 1. Edge 智慧分頁控制腳本
* **運作原理**：透過微軟原生的 UIAutomation (UIA) 底層介面直接解析瀏覽器分頁結構，取代傳統盲目發送快捷鍵的做法。
* **主要功能**：
  * **相對切換**：透過 `Ctrl + 1~5` 與 `Ctrl + Shift + 1~5` 往右或往左跳轉指定數量的分頁。
  * **邊界防護**：當跳轉超過範圍時，會自動停在第一頁或最後一頁，避免瀏覽器原生的循環切換現象。
  * **絕對跳轉**：提供 `Ctrl + 0` 直達第一頁、`Ctrl + 9` 直達最後一頁。
  * **快速首頁**：使用 `Ctrl + Shift + H` 快速導向瀏覽器設定的首頁。

## 2. 日規鍵盤 (JIS) 映射美規 (ANSI) 暨防干擾腳本
* **運作原理**：將日規鍵盤的實體鍵位重新對應至標準美規 ANSI 符號，並針對 Windows 微軟注音輸入法 (IME) 的底層機制進行深度優化。
* **主要功能**：
  * **防注音誤切換**：利用雙重的 `vkE8` 遮罩阻斷機制，完美解決 AHK 自動還原 Shift 修飾鍵時，導致輸入法被誤判為中英切換的 Bug。
  * **IME 緩衝區相容**：改用標準虛擬按鍵發送（而非強制文字注入），確保在打中文尚未按 Enter 決定的底線狀態下，輸入符號能正常接在中文後方，不會倒置到文字前方。
  * **特規鍵防錯位**：針對美規鍵盤沒有的 `¥` 鍵，內建 IME 狀態偵測；當偵測到正在輸入中文緩衝區時，會自動提前送出中文，防止游標錯位卡在文字與符號中間。
